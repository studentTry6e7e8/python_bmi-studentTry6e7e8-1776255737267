# Python_BMI

Write a program to calculate the Body Mass Index (BMI) according to the input weight kilograms) and height (in meters) of an adult, and then output the weight status ("Other
"Overweight", or "Obesity") based on her/his BMI.
The formula of BMI calculation: BMI = weight / (height)?
The inputs to your program will be weight and height in order.

Logic:
BMI < 25: "Other"
25 ≤ BMI < 30: "Overweight"
BMI ≥ 30: "Obesity"
